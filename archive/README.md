# Archive

Superseded versions live here and are never deleted. If a party signed version
1.0 of a document, they can always read version 1.0.

## Layout

```
archive/<document-version>/<file>
```

For example, when the Explore Agreement moved from 1.0 to 1.1, the 1.0 text is
copied to `archive/1.0/explore-agreement.md` in the same commit that published
1.1. The same path is served at
`https://mergecombinator.com/standard/archive/1.0/explore-agreement.md`.
